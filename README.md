# CompuTax Client File Downloader

A local web app that copies a client's `ITRV_<id>.pdf` and `Computation_<id>_<year>_<n>.pdf` files from a CompuTax data folder for selected assessment years. It runs on Windows, macOS and Linux and needs no installed dependencies.

Status: planning. See [docs/plan.html](docs/plan.html) for the system and UI design.
